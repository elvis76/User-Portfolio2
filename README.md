# Portfolio

A simple React + Vite portfolio.

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build in /dist
```

## Make it yours

- Edit `src/data.js` for your name, bio, email, skills and projects.
- Set `openToWork: false` there to hide the "Open to opportunities" badge.
- Colours live at the top of `src/styles.css`.
